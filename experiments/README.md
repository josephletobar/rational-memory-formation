# Experimental scripts

This directory holds exploratory and study-specific code that accumulated
during the project. It is grouped here so the root directory exposes the
reusable pipeline more clearly.

Contents include canonical and DINO/DINOv3 surprise variants, rendering and
visualization experiments, robustness and window/stride sweeps, remote Pod
and cache orchestration, and legacy data-download jobs.

These scripts may contain dataset-specific paths or assumptions from the
original runs. Check the script arguments and environment before reuse.
